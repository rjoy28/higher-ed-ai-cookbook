# The Higher Ed AI Cookbook

Recipes that help small colleges use AI well: practical, checkable, and built for teams without a dedicated analytics staff.

Each recipe is a four-file bundle:

| File | What it's for |
|---|---|
| **README** | Orients a human, explains the configuration, and says what the recipe deliberately does not do |
| **Agent Instructions** | The prompt you paste into your AI assistant |
| **Input Template** | A blank sheet with the expected columns and an example row |
| **Sample Output** | A fully worked example, so you can see the finished shape before you start |

All sample data describes **Riverside Christian University (RCU)**, a fictional institution. Any resemblance to a real college is coincidental.

## How to use a recipe

1. Open the recipe's folder and read its README.
2. Fill in the Input Template with your own institution's data.
3. Paste the Agent Instructions into your AI assistant and attach the filled template.
4. Compare what comes back against the Sample Output, and check the numbers before you circulate anything.
5. Take the result to the people who decide. A recipe supports a human decision; it doesn't make one.
