Read with care. A start is credited to the first source the CRM recorded for that person. A student who heard about RCU from an alumna and later clicked an ad counts as a referral. Cost per start is a fair comparison between channels, not the full cost of recruiting a student: it leaves out staff time, events and the website.

When does a gap count?

Each channel's platform counts inquiries before admissions does. Some gap is normal: spam, test submissions, a person who fills in two forms. A month is flagged when the gap is larger than the tolerance and the counts differ by at least the minimum.

One source per stage

Each number on this page comes from exactly one named source, and someone keeps it. Two sources count inquiries, which is why the tracking audit exists.

The crosswalk

Admissions records a source code. The crosswalk says which channel each code belongs to. A code nobody mapped can't be priced, and the spend behind it can't be traced to a start.

Behind the page

This page applies the Source-to-Start Reconciliation recipe to a synthetic cycle. In the recipe, an AI assistant joins ad spend and platform counts to an admissions export, returns cost per inquiry, application and start by channel, audits the tracking month by month, and drafts recommendations tagged research-backed, industry practice, or analyst judgment. Marketing and enrollment leadership decide.

It applies the fact source per control axis pattern to the funnel: each stage names the one source that answers it. The numbers match the Enrollment Funnel recipe's Fall 2026 online and graduate segments.
