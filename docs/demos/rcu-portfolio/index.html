Select a column heading to sort. Growth rate is the compound annual rate from the first to the last census year. Programs under the small-base line show net change as the better read, because a few students move the rate a lot.

Where the growth came from

Program labels can hide a pattern that only shows up in the rollup. This view adds programs up by school and level, using the same thresholds as the Scorecard.

Quiet decline

Programs losing students but still inside the Stable band. The recipe calls this a watch, not a reaction.

Largest shares of enrollment

A single program at or above the concentration line is a dependency risk. Between the watch line and the concentration line is a watch.

What this page does not do. It applies the recipe's rules and shows where they land. It does not recommend Grow, Maintain, Restructure, or Sunset. In the recipe, an AI assistant drafts those, each tagged by evidence basis, and faculty governance and cabinet decide.

Enrollment size is not revenue. RCU Program Economics joins net tuition and section data to the same programs.

The source

This YAML is the whole demo. Change a headcount, add a program, or edit the settings, then select Apply to re-render every view. Edits stay in this browser tab until you copy them out.

meta.years
Census years, oldest first. Every program's headcount list follows this order.
settings
The recipe's thresholds, from the Input Template's Config tab. The sliders start here, and Recipe defaults returns to these values.
programs
One entry per program: name, level, school, online share in the latest year, headcount by year, and an optional note. Use null for a year the program did not exist.
Shape
The same data as the Input Template's long shape (one row per program per year), folded so it is easier to read and edit.

Riverside Christian University is a fictional fixture institution, and its data is synthetic. It matches the sample output in the Academic Portfolio Analyst recipe.
