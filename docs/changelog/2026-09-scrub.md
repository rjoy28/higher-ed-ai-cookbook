# Bundle scrub — vendor names to capability labels, WCAG 2.1 → 2.2

Applied to the recipe bundles so the downloadable files match the published recipe pages.
Scope: sample outputs, input templates, READMEs, and agent instructions.

**Principle applied:** the function lives in a dedicated column (`Application` in Software
Portfolio, `Category` in Vendor Renewal), so capability labels go there. The identifying
vendor column keeps a neutral token (`Vendor A`…`Vendor Q`) rather than a capability label,
because vendor-to-function is not one-to-one across institutions — and because vendor
*grouping* drives a real finding (one supplier holding several products).

## Verification performed

- Residual-name scan across all 72 bundle files, using a 70-term vendor list.
- Formula preservation: 141 / 76 / 344 / 7 formulas intact in the four formula-bearing workbooks.
- Headless recalculation of the three edited sample outputs: **zero** `#REF!`, `#N/A`, `#VALUE!`.
- Vendor-concentration integrity: `Vendor F` still resolves to 3 products ($121,000 combined),
  `Vendor E` to 2 — the consolidation finding survives the rename.
- Figures for recipes 02, 03, and 07 regenerated **from the scrubbed workbooks**, so chart labels
  and bundle contents come from one source.
- 17-point audit of published page claims against scrubbed workbook values: all passing.
- WCAG: every criterion cited in the sample (1.1.1, 1.2.2, 1.3.1, 1.4.3, 2.4.4, 3.3.2, 4.1.2)
  exists in 2.2, and 4.1.1 Parsing — removed in 2.2 — was not cited, so the bump is clean.

## Deliberately not changed

**Brand / Media (12) — media outlet names.** The clip-log fixture names real publications and
broadcasters, and attributes invented coverage to them, including the negative sentiment on the
Title IX topic. Two rows also name a video platform as an owned channel. This is a different
category from software-vendor labelling and a separate editorial decision, so it was left intact
rather than half-scrubbed. Recommended treatment, if wanted: replace outlet names with outlet
*types* — regional public radio, higher-education trade publication, denominational news service,
local alt-weekly, network TV affiliate — which removes invented attribution while keeping the
owned-versus-earned split that the recipe is built on. No figure depends on outlet names.
