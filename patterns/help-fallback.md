# `/help` fallback

**The pattern:** Every agent answers `/help` with:

- the kinds of help it offers
- who built it, and how to reach them
- when it was built
- a pointer to the source artifact it reads from
- a plain directive to find a competent human before trusting it too far

**Why it matters:** Users inherit agents they didn't build. `/help` makes an agent's limits and provenance discoverable without reading the prompt.
