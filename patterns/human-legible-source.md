# Human-legible source

**The pattern:** An agent reads from a human-legible artifact, such as the same dashboard, sheet or report a person would use, rather than from a private feed only the agent can see.

**Why it matters:** When the agent and the human look at the same thing, anyone can check the agent's work. When they diverge, errors stay invisible until they cost something.

**In practice:** Every recipe's Input Template is a sheet a person can open, read and correct before the agent ever touches it.
